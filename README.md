# 에듀잇티 나이스 에듀파인

나이스와 K-에듀파인의 자주 쓰는 메뉴로 **버튼 한 번에** 들어가는 런처입니다.
로그인 한 번이면 두 시스템이 함께 열립니다.

## 설치

[**최신 버전 받기**](../../releases/latest) 에서 `eduitit-neis-edufine-setup-*.exe` 를
받아 실행하세요. 관리자 권한 없이 설치됩니다.

서명하지 않은 프로그램이라 처음 실행할 때 Windows 보호 화면이 뜹니다.
**추가 정보 → 실행** 을 누르면 됩니다.

## 쓰는 법

1. **로그인** — 인증서로 한 번 로그인하면 두 시스템이 함께 열립니다. 내 메뉴도 이때 자동으로 준비됩니다
2. 검색창에 메뉴 이름을 넣고 고르면 바로가기가 생깁니다
3. 그 카드를 누르면 해당 화면이 바로 열립니다

카드는 **끌어서 순서를 바꿀 수 있습니다.** 자주 쓰는 것을 앞에 두세요.
메뉴 종류는 그림으로 구분됩니다 — 문서·결재 📄 / 복무·출장·연가 🗓️ / 예산·지출 💰 / 인사 👤

공용 PC 에서 쓰신다면 자리를 뜰 때 **설정 → 로그아웃** 으로 저장된 세션을 지우세요.

문제가 생기면 **설정 → 기록 폴더 열기** 에서 `launcher.log` 를 꺼내 보낼 수 있습니다.

메뉴 목록은 코드에 넣어두지 않고 각자 PC 에서 가져옵니다.
교사마다 권한에 따라 보이는 메뉴가 다르기 때문입니다.

## 업데이트

앱이 실행될 때 스스로 확인합니다. 새 버전이 있으면 받아둔 뒤 다시 시작할지 물어봅니다.
몰래 설치하지 않습니다.

학교망에서는 GitHub 연결이 간헐적으로 끊겨 자동 업데이트가 실패할 수 있습니다.
그럴 때는 위의 설치 파일을 직접 받아 설치하세요. 바로가기와 로그인 세션은 그대로 유지됩니다.

## 이용 안내

앱을 처음 실행할 때도 같은 내용을 보여드립니다.
설치 후에는 **설정 → 이용 안내 · 라이선스** 에서 다시 볼 수 있습니다.

### 공식 프로그램이 아닙니다

교육부, 한국교육학술정보원(KERIS), 경기도교육청과 무관한 개인 제작 도구입니다.

어느 기관의 공식 제품도 아니며, 승인이나 지원을 받지 않았습니다.

"나이스", "K-에듀파인", "업무포털" 은 각 기관의 시스템 명칭이며, 이 프로그램이 어떤 시스템을 다루는지 가리키기 위해서만 사용했습니다.

### 하는 일과 하지 않는 일

사용자 본인 계정으로 로그인하고, 본인에게 이미 있는 권한 안에서만 동작합니다.

브라우저로 직접 하는 것과 같은 요청만 보냅니다. 인증을 우회하지 않습니다.

업무 자료나 개인정보를 읽거나, 모으거나, 외부로 보내지 않습니다.

### 저장되는 정보

아래 정보는 이 PC 안에만 저장되며 외부로 전송되지 않습니다.

- 로그인 세션 — 브라우저 쿠키와 같은 성격입니다

- 즐겨찾기와 내 메뉴 목록 — 메뉴 이름과 번호뿐입니다

- 실행 기록 — 문제가 생겼을 때 확인하는 용도입니다

공용 PC 에서는 자리를 뜰 때 [로그아웃] 을 눌러 세션을 지우세요.

모두 지우려면 프로그램을 제거하면 됩니다.

### 보증하지 않습니다

이 프로그램은 있는 그대로 제공되며, 동작이나 결과를 보증하지 않습니다.

사용으로 인해 발생한 손해에 대해 제작자는 책임지지 않습니다.

결재·복무처럼 중요한 업무는 공식 경로에서도 확인하시기 바랍니다.

대상 시스템이 개편되면 예고 없이 동작하지 않을 수 있습니다.

### 오픈소스 고지

Electron, Chromium, Node.js, electron-updater 등 오픈소스 소프트웨어를 사용합니다 (MIT · BSD · ISC).

각 라이선스 전문은 설치 폴더의 LICENSE.electron.txt 와 LICENSES.chromium.html 에 들어 있습니다.

## 이 저장소는 무엇인가

설치 파일과 설정만 배포하는 곳입니다. 소스 코드는 별도의 비공개 저장소에 있습니다.

교육청이 시스템 주소를 바꾸면 릴리스에 포함된 `config.json` 만 갱신하면 되고,
프로그램을 다시 설치할 필요가 없습니다.
