# 에듀잇티 나이스 에듀파인 — 배포

나이스와 K-에듀파인의 자주 쓰는 메뉴로 버튼 한 번에 들어가는 런처입니다.

## 설치

[**최신 버전 받기**](../../releases/latest) 에서 `eduitit-neis-edufine-setup-*.exe` 를
받아 실행하세요. 관리자 권한 없이 설치됩니다.

서명하지 않은 프로그램이라 처음 실행할 때 Windows 보호 화면이 뜹니다.
**추가 정보 → 실행** 을 누르면 됩니다.

## 쓰는 법

1. **통합 로그인** — 인증서로 한 번만 로그인하면 두 시스템이 함께 열립니다
2. **메뉴 목록 갱신** — 본인 권한의 메뉴를 가져옵니다 (처음 한 번)
3. 검색해서 메뉴를 고르면 버튼이 생기고, 누르면 바로 그 화면으로 갑니다

공용 PC 에서는 자리를 뜰 때 **로그아웃** 을 눌러 저장된 세션을 지우세요.

## 업데이트

앱이 실행될 때 스스로 확인합니다. 새 버전이 있으면 받아둔 뒤
다시 시작할지 물어봅니다. 몰래 설치하지 않습니다.

## 이 저장소는 무엇인가

설치 파일과 설정만 배포하는 곳입니다. 소스 코드는 별도의 비공개 저장소에 있습니다.

교육청이 시스템 주소를 바꾸면 릴리스에 포함된 `config.json` 만 갱신하면 되고,
프로그램을 다시 설치할 필요가 없습니다.

## 보안

- 인증서 비밀번호를 저장하지 않습니다
- 로그인 세션은 각자 PC 에만 저장되며 **로그아웃** 으로 지울 수 있습니다
- 교육청 도메인 밖의 주소는 앱 안에서 열지 않고 기본 브라우저로 넘깁니다
- 사용자 본인 권한 안에서만 동작합니다
